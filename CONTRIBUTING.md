# Contributing

Contributions are welcome for research and educational use.

1. Fork the repository and create a feature branch.
2. Keep new models explicit about units and assumptions.
3. Add or update tests for numerical changes.
4. Do not describe synthetic simulation results as operational or flight-tested performance.
5. Run `pytest -q` before opening a pull request.

Useful contribution areas include higher-fidelity sensor models, 6-DOF navigation, public gravity-map ingestion, robust estimators, and benchmark reproducibility.
