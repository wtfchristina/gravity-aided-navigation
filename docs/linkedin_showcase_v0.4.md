# LinkedIn Showcase — v0.4

I expanded my Gravity-Aided Navigation / Assured PNT research demonstrator into a mission-requirements and integrity-analysis suite.

Instead of only asking how a simulated sensor configuration performs, v0.4 can now ask a more useful engineering question:

**What sensor accuracy and update rate are required to satisfy a defined navigation target during a GNSS outage?**

New capabilities include:

- requirements-driven Monte Carlo sensor sweeps
- empirical success-probability scoring
- mission-envelope studies across outage duration and speed
- alert-limit monitoring and integrity-analysis proxies
- automated CSV/JSON outputs for engineering review
- CLI and Streamlit workflows

The existing platform still supports INS-only, gravity-aided, magnetic-aided, fused environmental navigation, cold-atom sensor modeling, observability analysis, and symplectic propagation benchmarks.

All results are synthetic research simulations — not flight-test, certified, or operational performance claims.

The larger goal is to move from a navigation demo toward an engineering decision-support tool for Assured PNT trade studies.
