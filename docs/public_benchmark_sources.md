# Authoritative Source References

## NGA EGM2008

Official product page: https://earth-info.nga.mil/index.php?dir=wgs84&action=wgs84

NGA describes EGM2008 as a normalized geopotential model complete to degree/order 2159 with additional coefficients to degree 2190/order 2159, and provides a 2.5-minute global interpolation product. NGA states EGM2008 is approved for official DoD use under its WGS 84 standardization documentation.

## NOAA/NGA WMM2025

Official product page: https://www.ncei.noaa.gov/products/world-magnetic-model

WMM2025 is the current World Magnetic Model for 2025-2030. NOAA distributes the model and calculator interfaces on behalf of NGA and provides the formal model citation and technical report. NOAA notes its WMM source code is public-domain U.S. Government material.
