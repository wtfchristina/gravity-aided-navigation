# v0.4 Commercial Value: From Simulator to Decision-Support Tool

Version 0.4 moves the project toward an engineering decision-support product.

## Buyer-facing questions the software can now address

1. What sensor performance is required to meet a mission navigation target?
2. What empirical probability of compliance is achieved across randomized runs?
3. How often does an integrity-analysis proxy exceed an alert limit?
4. Which mission duration/speed combinations can be supported by the modeled sensor suite?
5. Which sensor/update configurations are least demanding while still satisfying the stated requirement?

## Recommended product boundary

Keep the public repository as a transparent research/core edition. Commercial extensions can add proprietary validated maps, customer sensor adapters, HIL/SIL interfaces, 6-DOF navigation, secure data handling, customer reporting templates, embedded benchmarking, and formal V&V/traceability.
