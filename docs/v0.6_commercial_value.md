# v0.6 Commercial Value: Integration SDK

Version 0.6 creates a clearer boundary between the public research core and customer-specific integration work.

## What changed

The package now provides:

- a Sensor Adapter SDK
- Python entry-point plug-in discovery
- authenticated optional gRPC transport
- optional TLS for gRPC integration
- a protobuf service contract for typed external clients
- a ROS 2 bridge
- transport-independent estimator gateway reuse

## Why this matters commercially

A customer no longer needs to modify the navigation algorithms to connect a proprietary sensor, simulator, or robotics stack. Their integration can live in a private adapter package and communicate through a stable packet contract.

This creates a natural product split:

**Open / Research Core**
- synthetic scenarios
- public estimator interfaces
- reference transports
- example adapters

**Commercial Integration Layer**
- proprietary sensor adapters
- customer map adapters
- custom ROS 2 IDL
- authenticated service deployment
- HIL/SIL integration engineering
- validated hardware configurations
- support and verification artifacts

The reference gRPC/ROS 2 implementations are not represented as certified avionics interfaces. Certification, cybersecurity hardening, and customer-specific assurance remain separate engineering activities.
