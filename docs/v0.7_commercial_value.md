# v0.7 Commercial Value

v0.7 closes a key gap between a research demonstrator and an engineering evaluation product: **customer data can now enter the same analysis pipeline used by the navigation algorithms.**

Potential buyer workflows include:

- import a proprietary gravity or magnetic map;
- select an illustrative or customer-defined sensor performance profile;
- run matched INS-only, single-field, and fused campaigns;
- quantify median and 95th-percentile terminal error;
- perturb map bias/scale/mismatch assumptions;
- export reproducible validation results;
- move the same estimator into SIL/HIL through the v0.5/v0.6 gateways.

This creates a clearer product boundary:

**Open research core:** algorithms, synthetic examples, public interfaces.

**Commercial Analyst:** validated map adapters, uncertainty models, batch campaigns, reporting, mission-specific trade studies.

**Commercial Integrator:** customer sensor adapters, ROS 2/gRPC/HIL interfaces, deployment support, proprietary map connectors, and assurance artifacts.

The public repository should not claim operational performance from bundled examples. Commercial value comes from applying the framework to a customer's actual mission assumptions, maps, sensors, and integration environment.
